Privacy Policy

Last updated: 2026-08-14

What this site is

This website is a static landing page for AsoFast, an open source app store optimization tool. It does not run server-side code, databases, or user accounts.

Data we collect

We do not collect personal information through this site. We do not use analytics scripts, advertising trackers, social media pixels, or third-party cookies. The only server logs are those managed by GitHub Pages, our hosting provider, and they are outside our control.

Cookies

This site does not set cookies.

Third-party services

The site links to the AsoFast GitHub repository and provides a contact email. We do not embed content from YouTube, Twitter, or other platforms.

Contact
